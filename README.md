# Maison Soleil

**Maison Soleil** è una pagina web responsive realizzata come esercizio di frontend development.

Il progetto è basato su un esercizio proposto da https://www.frontendmentor.io , una piattaforma dedicata alla pratica dello sviluppo frontend attraverso challenge e layout da ricreare.

Il design e il concept della pagina sono stati utilizzati come riferimento per l'esercizio. L'implementazione è stata realizzata da me utilizzando HTML5 e CSS3, con particolare attenzione alla struttura semantica, al layout responsive e all'utilizzo di Flexbox e CSS Grid.

## Obiettivo

L'obiettivo dell'esercizio è ricreare una pagina web partendo da un design di riferimento (https://www.frontendmentor.io/challenges/hotel-booking-confirmation-page), concentrandosi esclusivamente sulle tecnologie frontend di base e senza utilizzare framework CSS o JavaScript.

Durante la realizzazione ho lavorato in particolare su:

* struttura semantica HTML;
* organizzazione e gestione del CSS;
* Flexbox;
* CSS Grid;
* responsive design;
* media queries;
* CSS variables;
* tipografia;
* spaziatura e allineamento;
* hover effects e transizioni.

## Features

## Layout

La pagina è composta da una sidebar e da un'area principale.

## Responsive Design

Il layout è progettato per adattarsi a diverse dimensioni dello schermo.

Sotto i 900px:

* la sidebar passa sopra al contenuto principale;
* le informazioni secondarie vengono nascoste;
* le card principali vengono disposte verticalmente;
* la griglia delle informazioni passa da tre colonne a una sola.
